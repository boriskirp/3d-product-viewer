## 🛠️ Tech Stack & Features
* **Three.js (r128)** & **OrbitControls** for flawless 3D rendering and camera navigation.
* **Contextual Interactive Deck:** Smooth focus switching between component sub-assemblies (Main Housing, Core, Nodes).
* **Fully Responsive:** Adapts instantly to desktop, tablet, and mobile displays.
* **Ultra-lightweight:** Zero heavy frameworks, pure vanilla JavaScript and CSS glassmorphism.
